# Pillbox audio assets

## Machine-gun fire

- **File:** `public/audio/pillbox-machine-gun-fire.mp3`
- **Title:** Light Machine Gun (`lmg_fire01.mp3`)
- **Creator:** KuraiWolf
- **Source:** https://opengameart.org/content/light-machine-gun
- **License:** Creative Commons Attribution 4.0 International (CC BY 4.0)
- **License text:** https://creativecommons.org/licenses/by/4.0/

The project copy is an adaptation. It was trimmed to a single short transient,
given a fast fade-out so repeated 8 Hz shots do not accumulate a long tail,
filtered, peak-limited, and re-encoded as a mono MP3. KuraiWolf does not endorse
this project.

Attribution must remain visible in any distribution that includes this asset:
“Light Machine Gun” by KuraiWolf, licensed under CC BY 4.0; modified for this
project.

## Reused project effects
