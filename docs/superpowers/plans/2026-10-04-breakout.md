# Stage 6: Breakout

Approved outcome: a compact playable Sherman tank mission after the bunker assault, with two village routes, destructible cover, telegraphed ambushes, component damage/repair, and a bridge holdout. Target first-play duration roughly five to eight minutes; actual pacing requires playtesting.

## Implementation slices
1. Deterministic tank simulation and village map (`lib/tank/`): independent hull/turret, cannon and MG, swept projectiles, collision/destruction, enemy warning/attack/cooldown, armor angles, track/turret damage, repair, demolition objective and bridge holdout. Verify pause/retry, collisions, damage, both routes, reachable win and loss.
2. Three.js scene: rounded tank hull/turret, road wheels and track motion, suspension and recoil, dimensional damaged buildings, hedgerows, bridge/river, sparks, dust and wreck smoke. Shared resources, bounded particles, mobile rendering budget.
3. Mission UI (`app/tank-game.tsx`), menu/campaign integration: independent mobile movement/aim/fire with capture-phase releases and interruption policy, desktop WASD/arrows/mouse, readable peripheral HUD, briefing, pause/retry/menu, Stage 5 victory continuation.
4. Integrated verification owned by primary agent: meaningful simulation/input tests, full project suite, typecheck/lint/build, browser desktop and mobile-layout checks. Read shared local CI reference and use existing runner where available; no project Tart guest exists initially. Retain evidence and state limits.

## Design
Reuse game typography. Palette: olive #596149, limestone #a89e89, slate #47535b, dust #beae8c, canvas #e8dfc9, warning #da895b. Battlefield fills viewport; compact top mission strip; bottom armor/reload readouts; touch pads in bottom corners. Briefing resembles a field order over the actual scene, with a simple route sketch. No enemy health labels floating over the world.

## Scope and review focus
One village, two routes, one enemy tank, several infantry/gun ambushes, three holdout attackers. Local implementation only; no new publication authority. No physics-engine dependency or full tank simulator. Review projectile occlusion, repair interruption, objective sequencing, mobile focus/releases, resource disposal, and bounded draw/entity counts.
